# 🎓 بوابة الطالب الأكاديمية - جامعة الجزيرة (الدفعة 43)
> **كلية العلوم الرياضية والحاسوب | Computer Science Student Portal**

مرحباً بكِ في المستودع الرسمـي لمشروع بوابة الطالب الأكاديمية، المخصصة لخدمة طلاب الدفعة 43 وتسهيل الوصول إلى المحاضرات، الجداول، المواد الدراسية، وأرشيف الامتحانات السابقة في مكان واحد.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)
تم بناء المشروع باستخدام التقنيات الأساسية لتطوير الويب:
* **HTML5** - لهيكل وتنظيم الصفحات.
* **CSS3** - للتصميم، التنسيق، والألوان المتناسقة مع هوية الكلية.
* **JavaScript** - لإضافة التفاعلات البرمجية والتحقق من البيانات.

---

## 📂 هيكل المشروع (Project Structure)
- `login.html` - واجهة تسجيل الدخول الآمنة للدفعة 43.
- `index.html` - الصفحة الرئيسية ولوحة الإعلانات الأكاديمية.
- `lectures.html` - قسم المحاضرات الدراسية مقسمة حسب التخصصات.
- `schedules.html` - جداول المحاضرات والامتحانات الأسبوعية.
- `exams.html` - أرشيف الامتحانات السابقة والأوراق الإرشادية.
- `subjects.html` - قائمة المقررات الدراسية للفصل الحالي.
- `account.html` - صفحة حساب الطالب وإدارة البيانات الشخصية.
- `script.js` - ملف الجافاسكريبت للتحكم بالتفاعلات البرمجية.
- `style.css` - ملف التنسيقات الشامل للموقع.
